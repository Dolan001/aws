# Inspect AWS target

Read the deployment contract, verified application evidence, runtime manifests, dependency locks,
container definitions, migrations, background workers, realtime needs, clients, existing `infra/`,
workflows, runbooks, and deployment evidence. Record processes, ports, health endpoints, secrets by
name only, storage, schedules, scaling signals, domains, environments, region/account assumptions,
and gaps. Do not invoke credential discovery, AWS APIs, plan, apply, DNS, or deployment commands.
